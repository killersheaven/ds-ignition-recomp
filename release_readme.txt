DSI Recomp - native PC version of Dead Space(TM) Ignition
Recompiled by Killers' Heaven, 2026.  https://github.com/killersheaven/ds-ignition-recomp

Unofficial fan project. Not affiliated with or endorsed by Electronic Arts.
NO GAME FILES ARE INCLUDED. You need your own copy of the Xbox 360 (XBLA) game.

WHAT YOU NEED
  - Windows 10 or 11, 64-bit, with a Direct3D 12 or Vulkan graphics card.
  - Your Xbox 360 copy of Dead Space Ignition (title ID 58410A7B), copied off the console's
    drive or USB stick. On the console it is the file with a long hex name in
      Content\0000000000000000\58410A7B\000D0000\
    Only the original 2010 XBLA release is supported; Setup checks every file.

FIRST TIME
  1. Unzip this folder somewhere you can write to (not Program Files). It needs about 2 GB.
  2. Run Setup.exe, pick your Xbox 360 package, press Install. It takes a few minutes.
     (Windows SmartScreen may warn about an unknown publisher: More info > Run anyway.)
     The PlayStation button symbols are drawn by DSI Recomp. If you also own the PS3 version you can
     tick the option to use its own symbols instead (folder: USRDIR\resource\sumotool).
  3. Run Launcher.bat.

LAUNCHER
  - Button prompts: Xbox 360, PlayStation 3 or Keyboard.
  - Skip EA and Visceral logos.
  - I own the full game (unlock trial): the XBLA package starts as the trial unless your
    console licence is present. Tick this only if you bought the full game.
  play.bat starts the game directly with the last launcher choices.

KEYBOARD
  Enter = Start    Space = A    Backspace = B    L = X    P = Y
  1 / 3 = LB / RB  Q / E = LT / RT    WASD = left stick    Arrow keys = right stick
  Xbox and other XInput controllers work as well.

TROUBLE
  - Game log: docs\run_windows.log.  Setup errors: setup_error.log.
  - Report problems on the GitHub page above (include the log).
